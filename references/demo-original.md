# AgentFlow - 现代混合智能待办调度工作台 (Web Demo)

基于 AI Agent 深度协作理念构建的轻量级现代化待办 Dashboard。零复杂构建步骤，纯前端单文件架构，直接双击或静态托管即可使用。

## 🌟 核心特性

- **AI 开发者工作台 (首页 - Workbench)**：
  - **默认首页**：进入即览全局，左侧导航首项为工作台，次项为待办调度中心，支持无缝双向切换。
  - **开发 Agent 调度与额度监控矩阵**：
    - 集中监控 **Codex (OpenAI)**、**Claude Code (Anthropic)**、**Cursor Agent**、**Devin (Cognition)**。
    - **实时状态流转**：清晰展示**空闲 (Idle)**、**忙碌 (Busy)** 与 **等待审批 (Waiting for Approval)**。
    - **交互式命令审批**：当 Agent 触发高风险终端命令时（如迁移脚本），卡片提供即时「✅ 批准执行」与「✕ 驳回」交互。
    - **额度获取与余量监控**：实时展示 Token / Fast Request / ACU 工时剩余额度、余额与百分比进度条，支持单个及「一键获取全部额度」同步刷新。
  - **关键待办速览中枢**：
    - **📅 今天的待办**：聚焦今日排期待办，支持行内一键快速完成打勾、优先级分类查看与即时新增。
    - **⚡ 进行中的待办**：直观跟踪正在推进的 Agent 协同任务，支持一键推进至「待验收」或快速复制 Agent 提示词。
    - **全向打通**：点击工作台上的任意待办均可即刻展开右侧抽屉查看详情/编辑/复制代码，或一键跳转完整看板。
- **左深右浅混搭现代美学 & 多主题系统 (Multi-Theme System)**：
  - **最左侧极窄边栏 (60px)**：高级深黑色科技感，沉稳内敛，带动态品牌发光与运行状态指示。
  - **左下角浮动主题切换**：支持点击与悬浮呼出浮动菜单，实时无缝切换 3 款高质感主题，带 `localStorage` 记忆持久化：
    1. **方案 2（默认）：Vercel / Notion 风格「极简单色黑白灰 Mono + 极克制点缀」**：以黑白灰的明度阶梯建立秩序感，深黑/石墨黑 (`#18181b`) 主交互色，轻浅底色徽标与边框，彩色仅保留给 6px 运行状态微点。
    2. **方案 1：Linear 风格「深邃冷靛蓝 / Electric Indigo」**：深邃冷靛蓝 (`#4f46e5`)，激活态浅蓝底 (`#eef2ff`)，页面背景微冷灰 (`#f8fafc`)，降低长时间阅读疲劳。
    3. **方案 3：复古高智感「焦糖陶土 / Terracotta」**：暖色系焦糖陶土 (`#c2410c` / `#9a3412`)，搭配暖石背景 (`#fafaf9`) 与边框 (`#e7e5e4`)，温暖复古且去塑料感。
- **自定义待办过滤中心 (二级浅色导航)**：
  - **时间规划维度**：收集箱 (Inbox)、今天、明天、某天、未来
  - **项目分类 (Categories)**：默认支持“工作”与“个人”，支持动态创建和管理自定义分类
  - **标签索引 (Tags)**：支持多维度标签聚合与过滤（如 `#backend`, `#frontend`, `#ai-agent` 等）
  - **优先级快速过滤**：P0 紧急、P1 高、P2 中、P3 低
- **三大核心视图自由切换**：
  1. **看板模式 (Kanban View - 默认)**：
     - 4 状态列：待处理、进行中、待验收、已完成
     - 支持**原生 HTML5 卡片拖拽流转状态**
     - 小尺寸紧凑卡片，清晰展示编号、Agent 标识、优先级徽章、项目路径
     - 卡片一键悬浮快捷复制
  2. **列表模式 (List View)**：
     - 紧凑表格视图，支持行内状态快速切换
     - 包含编号、标题、项目路径、优先级、分类、标签与快捷动作
  3. **大日历模式 (Big Calendar View)**：
     - 完整的 7x6 月度全景日历网格
     - 支持**年月切换**、**回到今天**、本月任务统计
     - **跨日期拖拽改期**：直接将任务卡片拖动到目标日期单元格，即可实时调整待办排期
     - 单元格右上角 `+` 支持在该日期快速新建排期待办
- **侧边划开抽屉 (Slide-over Drawer)**：
  - 点击任何待办卡片或新建按钮平滑滑出
  - 包含字段：标题、排期日期、编号、状态、优先级、分类、多选标签
  - **📂 项目路径 (Project Path)**：由 AI Agent 自动附带的源码工程路径（支持一键填入当前仓库），方便定位
  - **Markdown 任务描述**：支持编辑模式与实时预览（内置 `marked.js` 代码块与列表渲染）
  - **🤖 一键复制给 Agent 描述**：自动将任务生成规范的 Markdown Prompt 提示词模版，带齐项目路径和上下文，可直接喂回给 AI Agent！
- **现代暗黑极简科技美学**：
  - 采用 Obsidian + Linear + Raycast + Vercel 开发者风格配色
  - 纯 CSS 零运行时开销 (Tailwind CSS + daisyUI)
  - 实时本地 LocalStorage 数据持久化，开箱即用

## 🚀 启动与使用方式

### 方式 1：浏览器直开（最推荐，零依赖）
直接双击打开 `index.html`，即可在 Chrome / Edge / Firefox / Safari 中完整体验所有功能。

### 方式 2：使用任意轻量 HTTP 服务器（可选）
如果您希望通过本地端口访问，可以在当前目录下执行：

```bash
# 使用 Python 启动
python -m http.server 8080

# 或使用 Node npx
npx serve .
```
然后在浏览器中打开 `http://localhost:8080` 即可。
